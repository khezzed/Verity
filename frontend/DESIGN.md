# Verity Design System

## Stack
- framework: Vite + React 18 + TypeScript
- styling: Vanilla CSS with semantic design tokens (`src/styles.css`)
- icons: lucide-react
- fonts: Newsreader (editorial display & verbatim quotes) + IBM Plex Sans (UI & tabular metrics)

## Mode & Visual World
- **Surface mode**: Operate (precision verification & citation-audit instrument)
- **Visual world**: Swiss archival verification monograph. Deep Oxford Navy navigation rail (`#0F1C2E`), cool stone-alabaster workspace ground (`#F4F5F7`), crisp white primary analytical sheet (`#FFFFFF`), `1px` architectural ink rules, and disciplined Prussian Cobalt (`#1D4ED8`) interactive focus.
- **Signature move**: Interactive Wald SPRT log-likelihood trajectory canvas fused directly into a split Fisher-Yates citation index & verbatim-quote monograph inspector inside one unified sheet (zero nested card cages).

## Quality Floor Decisions
- Zero eyebrow kickers above headings.
- Zero side-stripe borders on boxes or quotes.
- Zero nested cards inside cards; regions separated by `1px` rules, whitespace, and subtle surface tint.
- Sentence-case UI labels and table headers; zero `< 13px` text above the fold.
- Themed browser surfaces (`::selection`, scrollbars, `:focus-visible`, `caret-color`, `tabular-nums`).
- Motion calibrated to one authored SPRT path entrance (`cubic-bezier(0.22, 1, 0.36, 1)`) with `prefers-reduced-motion` guard.
